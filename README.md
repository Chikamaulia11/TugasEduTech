# TugasEduTech
Repositori ini dibuat untuk mendukung kegiatan Edu Tech Study Club dalam mengerjakan dan mengumpulkan tugas-tugas yang diberikan.
Semua anggota diminta untuk melakukan Pull & Push terhadap repositori ini sebagai bagian dari praktik penggunaan Git dan GitHub dalam kolaborasi proyek.

Cara berkontribusi:
Fork repositori ini ke akun GitHub masing-masing.

Clone hasil fork ke lokal.

Buat cabang (branch) baru dengan nama tugasmu.

Tambahkan atau ubah file sesuai instruksi tugas.

Commit dan push perubahanmu ke GitHub.

Buat pull request ke repositori utama ini.
