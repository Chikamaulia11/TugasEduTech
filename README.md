Repositori ini dibuat untuk mendukung kegiatan Edu Tech Study Club dalam mengerjakan dan mengumpulkan tugas-tugas yang diberikan.
Semua anggota diminta untuk melakukan Pull & Push terhadap repositori ini sebagai bagian dari praktik penggunaan GitHub dalam kolaborasi proyek.
Silahkan untuk mengerjakan tugasnya dengan cara seperti berikut :
1. Fork repositori ini ke akun GitHub masing-masing.
=> Fork Github ini kedalam akun Github masing-masing. nanti akan ada repo copyan dari akun ini.

2. Untuk mengedit tugas diluar github. Clone hasil fork ke lokal(computer).
=> Anda dapat mengedit tugasnya di luar github. dengan clone/download tugasnya, jikalau nanti tugas berbentuk codingan yang harus disolve.

3. Buat cabang (branch) baru dengan setiap tugas yang diberikan.
=> semisal ada tugas dari Repositori TugasEduTech dengan nama filenya "coding prob-solve 1".
=> silahkan membuat branch baru di repositori kamu bernama sama yang ada di file ini("coding prob-solve 1").

5. Tambahkan atau ubah file sesuai instruksi tugas.

6. Commit dan push perubahanmu ke GitHub (repositorimu).

7. Buat pull request ke repositori "TugasEduTech" Fikriansyah000.
